## 誤りを見つけたら

[正誤報告フォーム](https://github.com/tomio2480/errata/issues/new/choose)から
報告してほしい．内容を確認のうえ，正誤表へ反映する．

報告から掲載までの流れは次のとおり．

1. フォームから Issue を起票する．
2. 著者が内容を確認し，正誤と判断したものへ「確認済み」ラベルを付ける．
3. 修正管理システムが執筆側へ引き継ぎ，Issue へ「転記済み」ラベルが付く．
4. 正誤表サイトへ掲載された後，Issue をクローズする．

## サイトの構成

- 正誤データ（`_data/`）と各書のページ（`books/`）は自動生成される．
  手動で編集しない．
- レイアウト（`_layouts/`）・トップページ（`index.md`）・スタイルは手動管理．
- アクセシビリティ水準は [ACCESSIBILITY.md](ACCESSIBILITY.md) を参照．
